# Teste do módulo gate/

## Descrição
Validação de propostas através de um sistema de 5 camadas com planeamento de falhas.

## Requisitos testados
1. Bloqueio de 100% das propostas defeituosas conhecidas
2. Taxa de falsos positivos ≤ 5% em propostas corretas
3. Recusa automática quando o validador falha internamente
