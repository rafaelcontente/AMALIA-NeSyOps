# Regras aplicadas

## Regras de geração de explicações
- Explicação gerada a partir do trace (não escrita depois)
- Cada frase tem referência explícita ao trace
- Zero afirmações órfãs (validação rigorosa)
- Duas vistas obrigatórias: cidadão e auditor

## Regras de linguagem
- Português europeu claro
- Frases curtas (< 25 palavras em média)
- Palavras-chave obrigatórias: "motivo", "referências"
- Para decisões indeferidas: "recurso", "prazo", "fundamentação legal"

## Regras de transparência
- Vista do cidadão: linguagem simples, próximos passos, direito de recurso
- Vista do auditor: IDs, versões, árvore de prova, regras avaliadas/violadas
- Modelo de Adverse Action Notices para decisões desfavoráveis
