# Teste do módulo explain/

## Descrição
Geração de explicações fiéis ao trace em português europeu claro.
Duas vistas: cidadão (linguagem simples) e auditor (técnica com IDs).

## Requisitos testados
1. Zero afirmações órfãs (todas as afirmações mapeiam para o trace)
2. Trace diferente → explicação diferente (não é texto fixo)
3. Compreensão do motivo e direito de recurso atinge limiar acordado
