# Teste do módulo compliance/

## Descrição
Documentação regulatória, rastreabilidade e mapeamento para frameworks (EU AI Act, RGPD, ISO, NIST).

## Requisitos testados
1. Cada regra ativa aparece na matriz com norma de origem, teste e última execução; uma regra sem ligação é apontada
2. O pacote é gerado automaticamente a partir de uma versão marcada (tag) e é reproduzível
3. Um jurista ou DPO revê o pacote do piloto e assina uma checklist a confirmar que cobre os requisitos aplicáveis
